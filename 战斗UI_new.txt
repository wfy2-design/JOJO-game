JOJO 战棋版 —— 战斗 UI 详细设计说明（新版）
（配合《规则介绍_战棋版.txt》与《角色数值与技能草案.txt》使用）

================================================================
〇、总览与设计原则
================================================================
1. 视觉基调：P5 骨架 × JOJO 血肉。
   - UI 骨架（菜单/血条/行动条/技能卡）：参考《女神异闻录5 皇家版》，
     红黑主色、斜切几何、粗描边、高对比、大量 easeOut 动效。
   - 画面血肉（角色/特效/文字）：JOJO 化——技能时替身显现、六维雷达图、
     拟声词大文字、漫画网点、高饱和撞色。
2. 核心原则：UI 是「演出的一部分」，不是「信息面板」；每个操作都有
   夸张动效反馈。
3. 分辨率基准：1920×1080；所有坐标按比例缩放，支持窗口缩放。
4. 与旧版差异：
   - 移除「T 下达指示/换人」（6 角色 3v3 满员，无换人）。
   - 新增「移动」机制（每回合免费 2 格，冲刺耗 1 AP 多 2 格）。
   - 新增：距离/命中预估、CTB 行动顺序条、六维雷达图、暴击（弱点击破
     特写）/时停表现。

================================================================
二、各区域详细规格
================================================================

----- ② 战斗棋盘 -----
1. 6×6 方格，斜 45° 俯视（棋盘菱形朝向镜头，便于表现纵深）。
2. 视角转换（对应《视角转换设定.txt》）：
   - 始终以当前行动角色为主视角；无论本地双人还是玩家对 AI，当前角色
     立绘放大、置于前景，其他角色缩小、靠后。
   - 行动者变化时镜头旋转/推拉并切换主副视角；棋盘逻辑坐标不随镜头改变。
   - 实现：主视角棋子 sprite 缩放 1.0，其他棋子 0.7；切换时 0.25s
     easeOut 过渡。
3. 格子状态配色：
   - 默认：深灰底 + 细网格线（约 #1A1C28）
   - 可移动范围：蓝色高亮（#3589E0，半透明 60%）
   - 冲刺可达：青绿色高亮（#42CDCA，半透明 80%，带外发光）
   - 普攻射程内：黄色描边（#FFD241）
   - 技能射程内：技能对应元素色（绿法皇=绿 #3FBF6F / 魔术师=红 #EE232F）
   - 不可达：灰暗、鼠标悬停显示「距离不足」
4. 选中目标：目标格红色粗描边 + 角色受击高亮；距离射线从攻击者连到
   目标（虚线，颜色随命中率变化：绿=高命中/黄=中/红=低）。
5. 同格显示与选择：同一格内多个棋子按固定 ID 错位并排显示；点击该格后
   弹出角色头像列表，可点击或按 Tab 切换单体目标。AOE 预览需同时高亮
   覆盖格中的全部敌方角色，友军显示为不受影响。

----- ⑥ X 形战斗键（底部，围绕当前行动角色） -----
1. 四键布局（沿用旧版 X 形，重定义按键）：

           技能 (E)
             ▲
             │
 防御 (C) ◄──●──► 攻击 (A)
             │
             ▼
        移动 (M/空格)

2. 各键功能：
   - A 攻击      ：进入选目标；高亮普攻射程（按 R_opt/R_max 衰减显示）。
   - E 技能      ：四键收回，展开技能页（见⑦）；Esc 返回四键。
   - C 防御      ：立即执行；角色摆防御姿态，本回合减伤 50%。
   - M 移动      ：进入移动模式（见下），移动不结束回合，可先移后动。
3. 视觉：四键为斜切六边形卡片，当前可用的键高亮、不可用灰化；
   鼠标悬停放大 1.1 倍 + 外发光；按下时 0.1s 下压回弹。

----- 移动模式（按 M 进入） -----
1. 进入后棋盘高亮「可达格子」：
   - 普通移动：累计 2 格（免费），蓝色高亮。
   - 冲刺：消耗 1 AP，额外 2 格（青绿高亮），每回合最多冲刺一次。
2. 操作：方向键 / WASD / 鼠标点击格子；按 M 或 Enter 退出移动模式
   （回到 X 形键，移动进度保留）；在行动确认前按 Esc 可撤销本回合全部
   移动，并恢复冲刺消耗的 AP。
3. 移动可穿过敌军和友军，也可停在其所在格。移动路径使用虚线轨迹 +
   落点光圈；冲刺带拖影特效。
4. 火墙按实际路径逐格结算：每次进入火墙格都会触发伤害，同一次移动中
   反复进入会重复触发。鼠标选择落点时显示完整路径，玩家可用方向键/WASD
   调整路径。

----- ⑦ 技能页（按 E 展开） -----
1. P5 式卡片列表，从底部滑入（0.2s easeOut）。
2. 技能列表字段：
   [技能名]   [AP 消耗]   [射程 X~Y 格]
   例：欧拉连打   3 AP   射程 0~1
3. 第一次选中卡片 → 右侧展示该技能的完整说明、倍率、状态持续时间与射程；
   再次选择同一技能后才确认发动。需要目标的技能随后进入棋盘选目标阶段，
   自身技能则在第二次选择时直接结算。
4. 确认发动后 → 棋盘高亮该技能有效射程格（技能自带射程，非普攻衰减）。
   距离 0 视为贴身；标注「射程 1」的近战技能高亮 0~1 格。
5. AP 不足的卡片灰化 + 红色「AP 不足」提示（呼应规则，无法释放需变更
   操作）。
6. Esc 返回 X 形四键（沿用旧版设定）。
----- ③ 行动顺序条（CTB，左侧竖排） -----
1. 展示接下来行动的角色头像队列，按速度条 S 升序（小者先动）。
2. 状态区分：
   - 当前行动者：放大 + 红色描边 + 轻微上下浮动（呼吸动效）。
   - 即将行动者：次亮；越靠前越亮。
   - 被减速/束缚/时停跳过：头像灰化 + 破碎/冰封特效。
3. 顶部显示回合计数。
4. 对应规则：S_init = 100/p，行动后 S += 100/p，平手按 p→ID 排序。

----- ④ 全员实时状态块（左下） -----
1. 六名角色始终按 A/B 队分组显示，不随当前行动者切换而隐藏：
   - 角色名、当前 HP/最大 HP、当前 AP/上限、速度条 S。
   - 防御、束缚、标记、蓄力等当前状态；退场角色灰显。
   - 当前行动者使用箭头与阵营色高亮。
2. 当前行动角色的六维雷达图可在后续 P1 阶段作为展开详情补充，不取代
   六名角色的常驻 HP/AP/S 信息。
3. 六维雷达图：
   - 六边形六轴：破坏力/速度/射程/持续力/精密度/成长性。
   - 评级映射刻度：A=100、B=80、C=60、D=40、E=20。
   - 选中/行动角色时，雷达图从中心向外「逐轴生长」动画（0.4s）。
   - 各角色六维（配合《角色数值与技能草案.txt》）：
       承太郎     100/100/60/100/100/100
       迪奥       100/100/60/100/80/80
       波鲁纳雷夫 60/100/60/80/80/60
       花京院     60/80/100/80/60/40
       阿布德尔   80/80/80/80/60/40
       乔瑟夫     40/60/40/100/40/20
4. 替身显现：仅在按下 E 技能键时，角色身后亮出替身立绘（见第四章「替身出现」）；普攻/防御/移动时替身不出现。

----- ⑤ 目标信息 / 命中预估面板（右下，选中目标时弹出） -----
1. 字段：
   目标：迪奥（世界）
   距离：5 格
   命中率：67%（基础命中率叠加技能/Buff 修正后的最终值）
   预估伤害：最小 24 ~ 最大 36（暴击）
   暴击率：20%
2. 命中率色彩编码：绿(≥80%) / 黄(50~79%) / 红(<50%)。
3. 计算口径（与规则文件一致）：
   - h(d) = 1（d≤R_opt）；(R_max-d)/(R_max-R_opt)（R_opt<d≤R_max）；
     0（d>R_max）。
   - 伤害 = 基础伤害 ×（暴击 1.5）×(1/(1+防御/50))，四舍五入。
   - 基础命中率 = h(d) × (1 - 运气/50)。
   - 最终命中率 = clamp(基础命中率 + 技能/Buff 的百分点修正, 0, 1)，再转为百分比显示；
     必中技能直接显示 100%。

三、回合交互流程（状态机）
================================================================
[CTB 弹出当前行动角色] → 镜头推近（主视角）
        │
        ├─ 移动阶段（可选，M 进入）：
        │     移动 0~2 格（免费）/ Shift 冲刺（+2 格，耗 1 AP）
        │     按 Enter/M 退出移动，Esc 撤销
        │
        └─ 行动阶段（X 形键）：
              A 攻击 → 高亮射程 → 选目标 → 结算
              E 技能 → 技能页 → 首选看详情 → 再选确认 → 选目标 → 结算
              C 防御 → 立即结算
        │
        ▼
[结算动画：命中/暴击/伤害数字/拟声词] → 速度条推进 → 下一位

按键映射表：
  E / A / C / M  ：技能 / 攻击 / 防御 / 移动
  方向键 / WASD  ：移动选格 / 菜单选择
  Shift         ：冲刺（移动模式下）
  Enter / Space ：确认 / 退出移动
  Esc           ：技能页返回四键 / 撤销移动 / 取消选目标
  Num1~Num4     ：技能页快速选技能（可选）
  Tab           ：同格存在多个角色时切换目标

四、反馈与特效（JOJO 灵魂）
================================================================
| 事件        | 特效                                                      |
|-------------|-----------------------------------------------------------|
| 普通命中    | 伤害数字弹出 + 命中闪光 + 轻微屏幕震动（2px）                |
| 暴击        | 弱点击破特写（见下）+ 拟声词砸屏 + 强震屏(6px) + 红色网点     |
| Miss        | 「MISS」斜体弹出 + 角色残影后撤                              |
| 时停        | 全屏灰阶冻结 + 波纹扩散 + 色差(CA) + 时钟定格音，仅使用者彩色 |
| 技能        | 技能名横版文字切入(P5) + 替身特写 + 元素色（绿/红）           |
| 退场        | 角色破碎消解 + 「REQUIEM」式定格                             |
| 移动        | 路径虚线 + 落点光圈；冲刺带拖影                              |

----- 替身出现（按 E 键触发） -----
1. 时机：仅当玩家按下 E 技能键时，当前角色身后亮出替身立绘。
2. 表现：替身立绘从本体身后浮现（淡入 + 放大 0.8→1.0，约 0.3s），
   配合拟声词「ゴゴゴゴゴ」。
3. 收起：按 Esc 返回四键、或完成技能结算后，替身淡出消失。
4. 素材：使用「角色 + 替身」合成立绘（一张 PNG），无需额外分层；
   若无合成立绘，可用替身单独立绘叠加在本体身后。
5. 其余时候（普攻/防御/移动/待机）替身不出现，保持画面简洁。

----- 暴击 → 弱点击破特写（P5 式，重点） -----
1. 触发：暴击判定成立（暴击率 = 暴击值/50，暴击伤害 ×1.5）。
2. 表现流程（约 0.8~1.2s）：
   a. 命中瞬间 Hit Stop 定格 30~60ms。
   b. 屏幕闪红/闪白。
   c. 在中央棋盘的战斗区域内插入「弱点击破」角色立绘特写，不遮挡
      左右状态栏、CTB、目标信息和底部操作区：
      - 构图：斜切构图（P5 风格），角色立绘放大，漫画网点/放射线背景。
      - 素材：使用 graph/graph/「角色名_弱点击破.png」。
      - 素材映射表见下。
   d. 拟声词「ドドド」砸屏 + 强震屏(6px)。
   e. 暴击伤害数字放大金色弹出。
3. 声效：
   - P5 式击破音（清脆「ブレイク」式音效，强调破防张力）。
   - 拟声词配合低频鼓点，音画同步。
4. 弱点击破立绘素材映射：
       承太郎    → graph/graph/承太郎_弱点击破.png
       花京院    → graph/graph/花京院_弱点击破.png
       波鲁纳雷夫 → graph/graph/波鲁纳雷夫_弱点击破.png
       阿布德尔  → graph/graph/阿布德尔_弱点击破.png
       迪奥      → graph/graph/迪奥_弱点击破.png
       乔瑟夫    → graph/graph/乔瑟夫_弱点击破.png（素材待补，由作者生成）

----- 时停特效细节（Shader 后处理） -----
  1. 全屏颜色 → 灰度（saturation = 0）。
  2. 以时停者为圆心扩散波纹（world-space distortion）。
  3. 边缘色差（红/青通道错位，chromatic aberration）。
  4. 屏幕中心叠加半透明时钟表盘，指针定格。
  5. 时停者自身保持彩色（排除后处理 / 单独绘制）。

八、实施分期
================================================================
  P0（可玩）  ：棋盘 + 血条/AP + X 键 + 技能页 + 目标距离/命中预估
  P1（手感）  ：六维雷达图 + 行动顺序条 + Hit Stop/震屏/延迟扣血
  P2（JOJO味）：拟声词 + 弱点击破特写 + 时停 Shader + 技能时替身显现 + 技能特写
