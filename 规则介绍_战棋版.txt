JOJO 回合制战棋版规则（整合修订版）

================================================================
〇、总体规则
================================================================
1. 双方各操控 3 名角色，共 6 名角色，一次性全部投放到棋盘上。
2. A 队 3 名角色开局均位于 (0, 0)，B 队 3 名角色开局均位于 (5, 5)，
   双方严格对角站位，初始曼哈顿距离均为 10。
3. 当某一方的所有角色全部退场（血量 <= 0）时，游戏结束，另一方获胜。
4. 目标引擎：Godot 4；战斗逻辑与画面/UI 表现分层实现。

【修订说明】本文件取代旧规则中的「逐人 1v1 投放」与「T 键换人」设定；
由于目前恰好 6 名角色（3v3 满员），不再设换人机制。

================================================================
一、棋盘与距离
================================================================
1. 棋盘为 6x6 的方形网格（可扩展至 8x8），坐标记为 (x, y)，x、y 均取
   0~5 的整数。
2. 距离定义采用「坐标曼哈顿距离」：
       d = |x1 - x2| + |y1 - y2|
   范围 0~10（对角两端最远为 10，同格重叠为 0）。
3. 移动、攻击、技能均以「距离 d」判定射程与命中。
4. 站位约定：允许同格重叠（同一格可存在多个棋子，距离 0 表示同格/贴身）。
   - 移动可穿过敌军和友军，也可停在已有棋子的格子。
   - 同格显示：多个棋子同格时，错位并排显示（各偏移约半格），避免遮挡。
   - 同格选取：使用单体攻击/技能时，必须从该格角色列表中明确选择目标。
   - 同格 AOE：某坐标被 AOE 覆盖时，该坐标内全部敌方角色均受影响；
     AOE 不伤害友军。
   - 战斗结算（命中/伤害/暴击/出手顺序）由既有规则决定，同格不产生
     额外结算歧义；出手顺序始终由行动条 S 决定。
5. 近战射程包含距离 0：技能标注「射程 1」时实际有效范围为 0~1 格；
   其他具有明确最低射程的技能（如 3~8）仍不能攻击低于最低射程的目标。

================================================================
二、角色数值
================================================================
1. 血量（HP）：每个角色的血量，当 HP <= 0 时退场（无法战斗）。
2. 行动点（AP）：每个角色有初始行动点，用于释放技能。
3. 伤害值：
   - 基础伤害值：面板直接定义的伤害（已体现该角色的破坏力差异）。
   - 攻击伤害值 = 基础伤害值（不再乘以独立的力量系数）。
   - 暴击：以「暴击值 b/50」的概率触发，暴击时攻击伤害 ×1.5。
   - 受到伤害值 = 攻击伤害值 × (1 / (1 + 防御/50))，最终四舍五入为整数。
4. 基础属性：
   - 暴击值 b/50：暴击率，b/50 的概率造成 1.5 倍伤害（取代原「力量」）。
   - 防御 y/50：决定受到伤害值（见上）。
   - 运气 z/50：有 z/50 的概率 miss 敌方攻击（敌方攻击不对角色造成伤害）。
     （注：运气为作者自设的独立词条，不具体对应替身六维图。）
   - 速度 p：决定行动条（详见「三、行动条」）。
5. 射程属性（新增）：
   - R_opt（最佳射程）：距离 <= R_opt 时，命中修正为 100%。
   - R_max（极限射程）：距离 >= R_max 时，命中修正为 0（无法命中）。
   二者为每个替身的固定面板属性，体现替身「射程」一维。

================================================================
三、行动条（CTB，修订版；取代旧「速度条 += p」规则）
================================================================
1. 速度条值 S：谁小谁先行动。6 名角色共用一个全局行动队列。
2. 初始速度条：
       S_init = 100 / p
   （K 取 100；速度 p 越大，S_init 越小，行动越靠前，速度决定先手。）
3. 行动结束推进：
       行动后 S = S + 100 / p
   速度越快，两次行动之间的间隔越短，行动越频繁。
   若本次行动中速度受到临时倍率影响，则只在本次行动结束时以有效速度
   计算增量；例如速度 ×1.5 时，本次增加 100/(p×1.5)，不重算当前 S。
4. 平手处理（保证确定性，无随机）：
   先比 S（小者先）→ 若相同比速度 p（大者先）→ 若仍相同比角色固定
   行动优先级 ID（编号小者先；ID 开局一次性固定，不随战局变化）。
5. 退场处理：角色退场后立即从行动队列移除，其 S 作废；其余角色
   继续按 S 排序，不重排初始值。

【修正说明】旧规则「行动后速度条 += p」会导致速度越快行动越慢，
本版改用「行动后 S += 100/p」，方向正确（速度越快行动越频繁）。

================================================================
四、每回合行动（修订版）
================================================================
每个角色的回合由「移动阶段 + 行动阶段」构成（博德之门式）：

【移动阶段】（免费，不消耗 AP，不占行动）
1. 普通移动：每回合免费移动 2 格（可 0~2 格）。
2. 冲刺：消耗 1 点 AP，额外移动 2 格（用于近战追击）。
3. 移动可穿过敌军和友军；移动效果按实际经过的逐格路径结算。
4. 在确认攻击、技能或防御前，可撤销本回合的全部移动；撤销后位置、
   移动次数、冲刺状态及冲刺消耗的 1 AP 全部恢复。行动一旦确认则不可撤销。

【行动阶段】（从下列动作中选 1 个）
1. 普通攻击（A 键）：不消耗 AP，并积攒 1 点 AP（常规值）。
2. 释放技能（E 键）：消耗技能对应的 AP；AP 不足时无法释放，
   系统提示并让玩家变更操作。
3. 防御（C 键）：不消耗 AP，防御状态下敌方伤害降低 50%（常规值），
   持续到该角色下一次行动开始。

【已移除】T 键换人：6 名角色已满员，不再设换人机制。

================================================================
五、距离与命中（新增；距离只影响命中，不影响伤害）
================================================================
1. 核心原则：距离仅作用于「命中率」，不改变「伤害数值」。
   伤害 = 基础伤害 ×（暴击时 ×1.5）× 防御减伤，与距离无关。
2. 命中修正 h(d) 随距离增大单调递减：

        d <= R_opt            → h = 1
        R_opt < d <= R_max    → h = (R_max - d) / (R_max - R_opt)
        d > R_max             → h = 0

3. 基础命中率 = h(d) × (1 - 运气/50)。
   最终命中率 = clamp(基础命中率 + 技能/Buff 的百分点修正, 0, 1)。
   必中技能直接取 100%，不受距离、运气及其他命中修正影响。
   （基础值由距离修正与运气 miss 概率相乘。）
4. 说明：距离越近，命中越高（近战、远程一视同仁，均无「近身衰减」）。
   近战替身贴脸的优势来自其基础伤害/连击更强，而非远程自身变弱。
5. 技能射程中的「1」按 0~1 格处理；形如「X~Y」且 X>1 的技能保留
   最低射程限制。距离 0 的同格单位始终属于近战目标。

================================================================
六、攻击结算（修订版）
================================================================
1. 一般情况下，针对某个角色的攻击只对该角色生效，不存在通用的
   替身挡枪 / 伤害转移机制。
2. 替身与本体共用一个血条（本体 HP 即替身 HP）。
3. 代伤 / 挡枪如需实现，仅作为特定替身的「特殊技能」存在
   （例如某角色的技能「替身守护」：本回合替指定相邻队友承受一次
   攻击），属于角色技能设计范畴，不设为通用规则。
4. 所有直接伤害默认可以暴击；点燃、火墙、反弹等持续/间接伤害不能暴击，
   除非技能文本另有说明。
5. 多段技能的每一段独立判定命中和暴击；目标在中途退场时，后续段数停止。
6. AOE 不伤害友军；同一坐标存在多个敌人时，每名敌人分别进行命中、
   暴击和伤害结算。

================================================================
七、时间暂停（修订版，方案乙）
================================================================
1. 时停过程中，只有时停的使用者可以在时停内行动。
2. 时停触发后：
   - 时停者本次行动后速度条 S 不推进（S 保持不变）；
   - 时停者额外获得一次完整的行动（可再移动并出手一次）。
   - 额外行动结束后，S 正常增加一次 100/p；整个时停过程只推进一次 S。
   - 时停额外行动期间不能再次释放时停，避免连续触发形成无限行动。
3. 效果：体现「DIO/承太郎 时停后抢占先手、瞬移贴脸」的压迫感，
   同时不破坏行动条的确定性。

================================================================
八、退场与胜负
================================================================
1. 角色 HP <= 0 时当场退场，从行动队列移除。
2. 一方所有角色全部退场 → 该方失败，另一方获胜。

================================================================
九、其他机制
================================================================
1. Buff/Debuff 机制：角色身上的状态随退场消失。「本回合」统一指从效果
   生效起持续到该角色下一次行动开始。
2. 速度条显示：屏幕左侧（或某固定区域）展示接下来几个回合的行动
   顺序预览，便于玩家判断谁将先手。
3. UI 风格：沿用《女神异闻录 5 皇家版》式 UI；角色周围以 X 形排布
   战斗键（A 攻击 / C 防御 / E 技能），按下 E 后切换为技能页，按 Esc
   返回。替身仅在打开技能页和技能演出期间出现，其余时候隐藏。
4. 点燃：在受影响角色行动开始时结算一次，共结算 2 次；点燃致死时立即
   退场，不能执行该次行动。
5. 场地效果按施放者的后续行动计时；火墙在施放者第二次后续行动开始时移除；
   若施放者提前退场，其创建的火墙立即移除。
   角色每次进入火墙格都受到一次伤害；同一次移动中
   反复进入会反复触发，强制位移进入时也会触发。伤害按实际路径逐格结算。
6. 游戏模式：同时支持本地双人和玩家对 AI。镜头始终以当前行动角色为
   主视角；视角切换不改变棋盘逻辑坐标和规则计算。
