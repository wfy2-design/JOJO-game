JOJO 战棋版 —— 菜单 UI 设计说明（Tab 键弹出）

================================================================
〇、设计理念
================================================================
1. 菜单不是「信息列表」，而是一场「角色演出」。
2. 核心手法：**每个菜单项绑定一位角色剪影 + 其专属主题色**。
   选中哪个菜单项，整个菜单就「变成」那个角色的颜色与剪影。
3. 参考《女神异闻录》系列的「全屏沉浸 + 立绘主导 + 处处动效 + 音效」，
   但**不以 P5 红黑为固定基调**，而是让每个角色用自己的颜色登场。
4. 全屏沉浸：按 Tab 时战斗画面定格 + 虚化 + 滤镜，菜单铺满全屏，
   不是小弹窗。

五、剪影 + 专属色的表现机制
================================================================
1. 角色剪影：选中项对应角色的大号剪影占据右侧，剪影用该角色主色
   填充/描边，背景加放射线或漫画网点。
2. 整体换色：菜单边框、选中高亮、标题、底部提示——全部动态切换
   到该角色主色（0.25s 颜色过渡）。
3. 拟声词点缀：切换菜单项时闪过该角色专属拟声词（见下表），强化
   记忆点。
4. 剪影素材：从现有立绘抠轮廓生成，无需额外手绘（见「十、素材」）。

七、各子页面规格
================================================================

----- ② 图鉴（人物 + 技能合一） -----
1. 左侧：6 角色竖排列表（头像 + 名字）。
2. 右侧：选中角色大立绘 + 六维雷达图 + 属性数值 + 一句背景故事。
3. 角色详情内嵌两个标签页：
   - 「属性」：HP / AP / 基础伤害 / 暴击值 / 防御 / 运气 / 速度 /
     射程 R_opt·R_max + 六维雷达图（逐轴生长，复用战斗 UI 动画）。
   - 「技能」：该角色技能卡片列表（技能名 / AP / 射程 / 倍率 / 效果）。
4. 六维雷达图逐轴生长动画（0.4s easeOut）。
5. 张力点：切换角色时立绘斜切滑入 + 该角色拟声词 + 主题色换色。

----- ③ 游戏介绍（规则图鉴） -----
1. P5 式分页卡片，左右翻页（← →），每页一个主题：
   - 页1 基本规则：3v3、全灭胜利、回合流程
   - 页2 距离与命中：6×6 网格示意图 + 曼哈顿距离公式 + 射程衰减曲线
   - 页3 行动条：CTB 队列示意图 + S = 100/p 公式
   - 页4 战斗机制：暴击（×1.5）、防御（-50%）、移动/冲刺、同格重叠
2. 每页配漫画网点背景 + 大标题斜切，翻页有「撕纸」动效。

----- ④ 设置 -----
1. 音量：BGM / SE / 语音（P5 式滑块）。
2. 显示：全屏/窗口、分辨率选择。
3. 返回标题：回到主菜单。

----- ⑤ 退出游戏 -----
1. 弹出确认对话框：「确定要退出吗？」（是/否）。
2. 对话框套用当前角色主题色。

九、字体与文字特效（Godot 4）
================================================================
1. Godot 4 内置字体能力：
   - FontFile：加载 TTF / OTF / WOFF / WOFF2 自定义字体。
   - FontVariation：支持可变字体轴（字重/宽度/倾斜），可动态做强调动画。
   - Label / LabelSettings：原生支持描边（outline_size / outline_color）、
     阴影、颜色、字号。
   - Theme 字体回退（fallback）：中文缺字自动回退到备用字体。
   - RichTextLabel：支持 BBCode、逐字显示（打字机效果）。
   - 默认字体为 Noto Sans（较平淡，建议替换为下方字体）。

2. 推荐字体（免费可商用，兼顾「张力」与 JOJO/P5 斜切风格）：
   用途           推荐字体                说明
   ----------------------------------------------------------------
   标题/中文      得意黑(Smiley Sans)     ⭐ 首选。开源倾斜粗黑体，
                                          斜切感极强，中英日全支持，
                                          天然贴合 JOJO/P5 的「斜切」
                                          视觉语言（OFL 许可）。
   标题/中文      站酷高端黑              免费商用，粗壮有力。
   正文/中文      阿里巴巴普惠体 Heavy    免费商用，粗细适中。
   数字/英文      Bebas Neue              窄高冲击力，适合大号伤害
                                          数字/标题数字（谷歌字体）。
   数字/英文      Anton                   更粗更方，适合强调。
   日文/拟声词    Yuji Syuku / Yuji Mai   毛笔手写风，适合「オラオラ」
                                          「無駄無駄」等拟声词。

3. Godot 4 文字特效（增强张力，无需额外素材）：
   - 描边：Label outline_size 2~4px + 角色主题色描边（P5 标志）。
   - 斜切：Label rotation / skew 属性做斜切标题（JOJO 速度线感）。
   - 强调动画：用 FontVariation 动态调字重，做「选中弹跳」动效。
   - 逐字显示：RichTextLabel 做技能名/剧情文字的打字机效果。
   - 抖动/弹出：对 Label 施加 Tween（scale/position 弹跳）。

4. 建议落地方案：
   - 全局标题字体 = 得意黑（斜切粗黑，覆盖中文+英文+假名）。
   - 正文 = 阿里巴巴普惠体 Heavy 或 思源黑体。
   - 伤害数字/菜单大数字 = Bebas Neue 或 Anton。
   - 拟声词 = Yuji 系列毛笔体（或得意黑假名 + 描边）。
   - 全部配合描边 + 斜切 + Tween 弹跳，替代呆板的宋体。

================================================================
十、剪影素材规格
================================================================
1. 每名角色绘制一张漫画写实比例全身立绘，统一为 1536×2048、透明背景 PNG。
2. 图鉴显示彩色原图；主菜单由 Godot Shader 读取同一张图的 Alpha 轮廓并填充主题色，
   不额外绘制剪影文件。
3. 最终文件放入 assets/menu/portraits/，使用 jotaro.png、dio.png、kakyoin.png、
   polnareff.png、avdol.png、joseph.png 六个英文文件名。
4. 最终素材未完成时，程序自动回退到 assets/characters/ 中的当前角色图作为占位。
5. 六名角色的具体构图、姿势、图层与安全区说明位于工程根目录 lihui/。

================================================================
十二、已确认的实现口径（2026-08-15）
================================================================
1. 主菜单五项固定显示为 CONTINUE / ARCHIVE / GUIDE / SETTINGS / EXIT；
   进入子页面后，人物、规则、设置和确认内容使用中文。
2. 图鉴数值显示 BattleData 中的固定基础值，不读取当前战斗中的动态 HP/AP/状态。
3. 返回标题会提示放弃当前战斗进度，确认后返回本地双人/玩家对 AI 模式选择页。
4. 项目逻辑分辨率保持 1600×900，并支持 1280×720、1600×900、1920×1080。
5. 首期支持键盘与鼠标，手柄输入后续追加。
6. 已引入 Smiley Sans、Source Han Sans CN、Bebas Neue、Yuji Syuku 及许可证。
7. 已建立 BGM / SE / Voice 音频总线与音量设置；当前不加入音乐、音效和语音素材。
8. Tab 菜单会暂停战斗树和 AI 计时，关闭后恢复进入菜单前的操作状态。
