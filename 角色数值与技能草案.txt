（基于《规则介绍_战棋版.txt》的新规则框架）

================================================================
一、设计总览
================================================================
1. 属性映射（战斗面板 ↔ 替身六维）：

   战斗面板          替身六维        说明
   ------------------------------------------------------------
   基础伤害          破坏力          面板伤害，体现破坏力差异
   暴击值 b/50       精密度          暴击率 = b/50，暴击 ×1.5
   防御 y/50         持续力          减伤 = 1/(1+y/50)
   速度 p            速度            行动条 S_init = 100/p
   射程 R_opt/R_max  射程            普攻命中随距离衰减
   运气 z/50         （自设词条）      miss 率，不对应六维
   成长性            （技能体现）     高成长者拥有「觉醒技」

2. 普攻与技能射程：
   - 普攻：使用角色的 R_opt / R_max 做命中衰减（见规则文件）。
   - 技能：每个技能自带「射程」有效格数范围（曼哈顿距离），
     范围内正常结算（仍受运气 miss 影响），范围外无法释放。
     必中类技能不受运气 miss 影响。
   - 距离 0 视为同格/贴身。「射程 1」统一表示 0~1 格；其他明确写出
     最低射程的远程技能（如 3~8）仍保留最低射程限制。
   - 所有直接伤害默认可暴击；点燃、火墙、反弹等间接伤害不可暴击。
     多段技能的每段独立判定命中和暴击，目标中途退场则停止后续段数。

3. 平衡目标：
   - 3v3 每队总 HP、总输出大体相当（见第五部分校验）。
   - 定位差异化：近战爆发 / 远程风筝 / 刺客 / AOE / 控场辅助。

五、平衡性校验
================================================================
1. 队伍总 HP：
   - A 队（承太郎/花京院/波鲁纳雷夫） = 240 + 160 + 140 = 540
   - B 队（迪奥/阿布德尔/乔瑟夫）     = 230 + 170 + 200 = 600
   B 队更肉，但 B 队输出被乔瑟夫（低伤害辅助）拉低，形成
   「A 队高输出脆皮 vs B 队低输出肉盾」的对位。

2. 基础伤害期望（含暴击期望，×1.5 暴击）：
   - 承太郎 32×(1+0.30×0.5)=36.8   迪奥 32×1.10=35.2
   - 波鲁纳雷夫 22×1.18=26.0        阿布德尔 26×1.08=28.1
   - 花京院 20×1.08=21.6            乔瑟夫 14×1.05=14.7
   主力输出（承太郎/迪奥）对位，中坚（阿布德尔）略高于刺客
   （波鲁纳雷夫），辅助（乔瑟夫）最低——符合定位。

3. 减伤（受到伤害 = 攻击 × 1/(1+y/50)）：
   - 承太郎 78% / 迪奥 81% / 乔瑟夫 81% / 阿布德尔 86%
   - 花京院 88% / 波鲁纳雷夫 93%（最脆，靠闪避与速度补偿）

4. 待实测调整项：
   - 近战在 6×6 对角开局下需突进 4~5 回合，突进成本是否过高，
     需实测后可能上调免费移动（如 3 格）或降低远程压制力。
   - 时停(AP 5) 成本高，需验证是否值得；可考虑 AP 4。
   - 乔瑟夫「波纹对 DIO ×1.5」是否过强，需在 DIO 对乔瑟夫对位中验证。

================================================================
六、落地提示（代码 / 配置字段变更）
================================================================
1. Character.h：`int strength` 改为 `int crit`（暴击值）；
   新增 `int rOpt`、`int rMax`（射程）。
2. ConfigParser.cpp：解析字段 `strength` → `crit`，新增
   `rOpt`、`rMax` 解析。
3. characters.cfg：字段变更
       strength=8  →  crit=15
       （新增）rOpt=1   rMax=6
   技能行可扩展为：技能名 cost=N mult=M range=lo~hi [必中/效果]
4. 现有 cfg 分组为 A=承太郎/花京院/波鲁纳雷夫、B=迪奥/阿布德尔/乔瑟夫；
   若叙事上需「主角团 vs DIO」，需另行调整分组（主角团 5 选 3）。
